# TOEIC Speaking 실전 트레이너

시험과 동일한 타이밍으로 녹음하고, 다시 듣고, 모범답안·만능 문장과 대조하는 **로컬 연습 도구**.
HTML / CSS / JavaScript만 사용한다. 빌드 없음, 의존성 없음, 서버 전송 없음.

## 실행

**Mac** — `app/start.command` 더블클릭
**Windows** — `app/start.bat` 더블클릭

서버가 켜지고 브라우저가 열린다. 창을 닫으면 서버도 종료된다.
포트가 쓰이고 있으면 비어 있는 포트를 자동으로 찾는다.

터미널을 쓴다면:

```bash
python3 -m http.server 8777 --directory app
```

### index.html 을 그냥 열어도 되나

**열린다. 다만 브라우저를 완전히 종료하면 녹음 오디오가 사라진다.**

`file://` 에서는 IndexedDB 가 에러 없이 열리지만, 브라우저를 완전히 끄면 origin 이 새로 잡혀
빈 DB 가 된다. 그래서 `file://` 로 열면 앱이 매 저장마다 학습 기록을 localStorage 에 복사해 두고,
다음에 열 때 되살린다.

| | index.html 더블클릭 | start.command / start.bat |
|---|---|---|
| 화면·문장 세트·드릴·TTS | 정상 | 정상 |
| 녹음·바로 재생 | 정상 | 정상 |
| 점수·메모·드릴 통계·커버리지 | **완전 종료 후에도 보존** | 보존 |
| **지난 녹음 오디오** | **완전 종료 시 소실** | **보존** |
| 마이크 권한 | 매번 다시 물을 수 있음 | 한 번만 |

오디오는 한 회에 수백 KB 라 localStorage(약 5MB)에 담을 수 없다. 그래서 오디오만 못 살린다.
**지난 녹음을 다시 들을 생각이면 실행 스크립트를 써라.**

Python 이 없으면 스크립트가 알아서 `index.html` 을 열고 안내한다.

## 기능

| | 내용 |
|---|---|
| **연습** | 2026년 현행 11문항 구조 그대로. 준비·답변 타이머, 자동 녹음, 재청취, 모범답안 대조, 자가 채점 |
| **문장 세트** | Part 2–5 유형별 만능 문장 70개 + 빈칸 채우기 드릴 4모드 (상황 310개) |
| **공식 자료** | ETS·한국TOEIC위원회 공식 자료로 이동하는 외부 링크 34개 |
| **기록** | 녹음 보관, 시간 활용률 추이, 반복 오류 메모 |

자동 발음 채점·STT·AI 분석은 **없다.** 채점은 자가 채점표로 직접 한다.

### 모의고사 출제

별도 전용 문제 없이 파트별 연습과 같은 풀에서 뽑되, 무작위가 아니라 **가중 추출**이다.

| 신호 | 가중치 |
|---|---|
| 아직 안 푼 문항 | 400 (최우선) |
| 자가채점이 낮음 | +0~120 |
| 오래 안 봄 | +0~90 |
| 여러 번 품 | −0~25 |

상위 N개를 그냥 자르면 다 푼 뒤 매번 같은 문항만 나와 굳는다. 그래서 이 값을 **확률 가중치**로 쓴다.
못한 문항이 자주 돌아오되 잘한 문항도 가끔 나온다. 기록이 없으면 순수 무작위로 되돌아간다.

11문항 · 약 20분 · 5개 과제 유형. 구 Part 5 *Propose a Solution* 은 2021-08-07 삭제되어 다루지 않는다.

## 데이터

녹음은 이 브라우저의 IndexedDB에만 저장된다. 서버로 전송되지 않고, 저장소에도 올라가지 않는다.
물리적으로는 브라우저 프로필 폴더 안에 있어서 이 프로젝트 폴더 밖이다 — git 이 볼 수 없는 위치다.

## 배포 (Cloudflare Pages)

빌드도 백엔드도 없는 정적 사이트라 그대로 올라간다.
**HTTPS 로 서비스되면 `file://` 제약이 전부 사라진다** — 녹음 오디오가 영구 저장되고
마이크 권한도 한 번만 묻는다. 스터디원은 링크만 열면 된다.

### 설정값

| 항목 | 값 |
|---|---|
| Framework preset | None |
| Build command | *(비움)* |
| Build output directory | `app` |
| Root directory | *(비움)* |

빌드 명령이 없으므로 Pages 가 `app/` 을 그대로 정적 호스팅한다.
해시 라우팅(`#/home`)을 쓰기 때문에 SPA rewrite 규칙이 필요 없다.

### 도메인 연결

Cloudflare 대시보드 → 해당 Pages 프로젝트 → **Custom domains** → 도메인 입력.

- 도메인이 **이미 Cloudflare 에 있으면** DNS 가 자동으로 붙는다. 클릭 몇 번이면 끝난다.
- 도메인이 **다른 곳에 있으면** 네임서버를 Cloudflare 로 옮기거나(무료),
  해당 등록기관에서 CNAME 을 Pages 주소로 지정한다.

기존에 쓰던 사이트가 그 도메인에 붙어 있었다면, 그 DNS 레코드를 지우고
Pages 로 다시 가리키면 교체된다.

### 배포해도 달라지지 않는 것

**녹음은 여전히 각자 브라우저에만 저장된다.** 서버로 올라가지 않는다.
이 앱에는 백엔드가 없어서 업로드할 곳 자체가 없다. 스터디원끼리도 서로의 녹음은 보이지 않는다.

`robots.txt` 로 검색 노출을 막아 두었다. 링크를 아는 사람만 쓰는 용도다.
