# TOEIC Speaking 실전 트레이너

시험과 동일한 타이밍으로 녹음하고, 다시 듣고, 모범답안·팁과 대조하는 로컬 연습 도구.
HTML / CSS / JavaScript만 사용한다. 빌드 없음, 의존성 없음, 서버 전송 없음.

## 실행

**Mac** — `app/start.command` 더블클릭
**Windows** — `app/start.bat` 더블클릭

서버가 켜지고 브라우저가 열린다. 창을 닫으면 서버도 종료된다.
포트가 쓰이고 있으면 비어 있는 포트를 자동으로 찾는다.

터미널을 쓴다면:

```bash
python3 -m http.server 8777 --directory app
```

### index.html 을 그냥 열어도 되나

**열린다. 다만 브라우저를 완전히 종료하면 녹음 오디오가 사라진다.**

`file://` 에서는 IndexedDB 가 에러 없이 열리지만, 브라우저를 완전히 끄면 origin 이 새로 잡혀
빈 DB 가 된다. 그래서 `file://` 로 열면 앱이 매 저장마다 학습 기록을 localStorage 에 복사해 두고,
다음에 열 때 되살린다.

| | index.html 더블클릭 | start.command / start.bat |
|---|---|---|
| 화면·문장 세트·드릴·TTS | 정상 | 정상 |
| 녹음·바로 재생 | 정상 | 정상 |
| 점수·메모·드릴 통계·커버리지 | **완전 종료 후에도 보존** | 보존 |
| **지난 녹음 오디오** | **완전 종료 시 소실** | **보존** |
| 마이크 권한 | 매번 다시 물을 수 있음 | 한 번만 |

오디오는 한 회에 수백 KB 라 localStorage(약 5MB)에 담을 수 없다. 그래서 오디오만 못 살린다.
**지난 녹음을 다시 들을 생각이면 실행 스크립트를 써라.**

Python 이 없으면 스크립트가 알아서 `index.html` 을 열고 안내한다.

## 문항 구성

모든 문항·지문·사진·모범답안은 **자체 제작**이다. ETS·한국TOEIC위원회의 공식 문항·사진·음원은
저작권 보호 대상이므로 복제해 넣지 않았다. 공식 자료는 `공식 자료` 탭에서 **외부 링크로만** 연결한다.

| 파트 | 수 | 커버 범위 |
|---|---:|---|
| Part 1 | 16문항 | 공지·안내, 광고, 방송·뉴스(지역·날씨·교통·인터뷰 소개), 전화 안내(자동응답·예약) |
| Part 2 | 10문항 | 실내(카페·회의실·상점·식당·도서관·강연장), 야외(공원·거리·시장·공항). 1인 중심 사진 포함 |
| Part 3 | 10세트 | 음식, 운동, 교통, 기술, 공부, 쇼핑, 여행, 여가, 직장, 외식 (세트당 3문항) |
| Part 4 | 7세트 | 워크숍·항공편·강좌표·컨퍼런스·투어·면접표·대여 요금표 (세트당 3문항, Q9는 정정형) |
| Part 5 | 10문항 | 정책 찬반, 두 선택지 비교, 선호, 효과적인 방법, 직장·교육·생활 |

Part 1 지문은 45초에 맞춰 **80–110단어**로 작성했다.

## v2 — 문장 세트와 빈칸 드릴

Part 2–5는 **유형 → 만능 문장 → 빈칸 드릴**을 제공한다. `문장 세트` 탭.

| 파트 | 구성 | 문장 |
|---|---|---|
| Part 2 | 골격 5블록 + 장면 4변형 | 3 |
| Part 3 | 8유형 (빈도/시점·장소/선호/YesNo/추천/서술/조언/의견) | 27 |
| Part 4 | 5유형 (단일조회/복수조회/정정/조건필터/대상전체) | 12 |
| Part 5 | 5유형 (찬반/비교/선호/방법/장단점) | 30 |

총 70문장 · 드릴 상황 310개.

**Part 1은 없다.** 지문을 그대로 읽는 과제라 채워 넣을 빈칸이 없다.

**Part 5의 구조** — 입장 문장만 유형별로 다르고 이유1·예시·이유2·양보·결론 5블록은 전 유형 공통이다.
외울 게 10문장이 아니라 6문장이라는 뜻이다.

### 드릴 4모드

| 모드 | 입력 | 시간 | 목적 |
|---|---|---|---|
| A 슬롯 채우기 | 타이핑 | 12초 | 빈칸에 뭐가 들어가는지 익히고 형식 검사를 받는다 |
| **B 연속 말하기** | **3·2·1 → 녹음** | 문장 길이만큼 | **답변 골격 전체 순회 — 핵심 드릴** |
| C 블록 조립 | 타이핑 | 20초 | 블록을 이어 완성 답안 |
| D 실전 타이밍 | 3·2·1 → 녹음 | 유형별 15·30·60초 | 실제 답변 시간으로 한 번에 |

모드 B는 답변 골격을 **문장마다 상황 3개씩 순회**한다. Part 2 라면 장소 도입 → 중심 동작 →
전체 인상 순으로 9문항이다. 템플릿은 화면에 고정되고 상황 카드만 바뀐다.
같은 문장을 반복하는 게 아니라 같은 골격으로 다른 문장을 만드는 것 — 통암기와 정반대의 훈련이다.

문장 하나만 파고 싶으면 유형 상세에서 **이 문장만 집중 드릴**을 누른다. 그 문장의 상황 5개를 전부 돈다.

녹음 시간은 **문장 길이에 맞춰 자동으로 정해진다**(6~18초, 평균 9.3초).
한 문장짜리 드릴에 15초를 주면 죽은 시간이 생겨 연속 드릴의 리듬이 깨지기 때문이다.

**시험은 타이핑이 아니라 말하기다.** 그래서 핵심 드릴을 음성으로 둔다.
카운트다운 3초는 Part 3 의 실제 준비 시간과 같다. 녹음은 자동으로 시작·종료되고
끝나면 바로 다시 듣기와 모범 예시가 뜬다. 타이핑은 형식 검사가 필요한 A·C 에 남겼다.

### 채점 범위

**형식 검사까지만** 한다. 필수 어휘 포함, 정규식 패턴, 최소 단어수, 빈칸 실제 채움, 골격 유지율.
내용이 질문에 맞는지는 판정하지 않는다. 대신 `이 상황의 모범 예시`와
`같은 골격 · 다른 내용` 예시를 함께 보여줘 정답이 하나가 아님을 드러낸다.

> ETS는 다른 응답·출판물과 실질적으로 유사한 답변에 점수 취소 권한을 명시한다.
> 만능 문장은 통암기용이 아니라 골격 자동화용이다.

### 루프

```
연습에서 녹음 → 리포트 하단 "이 문항의 유형" → 만능 문장 → 빈칸 드릴 → 리포트로 복귀 → 재녹음
```

문장 세트·드릴로 넘어가면 화면 위에 **복귀 줄**이 남아 리포트로 한 번에 돌아온다.
드릴 중간에 나가도, 끝까지 완주해도 마찬가지다.
링크를 ⌘(Ctrl)+클릭하면 새 창에서 열려 리포트를 그대로 둘 수도 있다.

Part 2 리포트에는 **블록 커버리지 체크**가 붙는다. 녹음을 들으며 실제로 말한 블록만 체크하면,
반복 누락된 블록이 누적 경고로 뜬다 (`최근 3회 반복 누락 — B4 배경·사물`).

## 무엇을 하는가

| 한다 | 하지 않는다 |
|---|---|
| 시험과 동일한 준비·답변 타이머 | 자동 발음 채점 |
| 지시문·질문 음성(TTS) 재생 | STT 전사 |
| 녹음, 재청취, 영구 보관 | AI 분석 |
| 시간 활용률 계산 | 공식 점수 환산 |
| 모범답안 + 문항별 팁 제시 | |
| 자가 채점표, 교정 목표 메모 | |
| 공식 자료 외부 링크 제공 | 공식 문항·음원 저장·재생 |
| 만능 문장 빈칸 드릴 · 형식 검사 | 내용 적절성 판정 |

채점은 자가 채점표로 직접 한다. **첫 청취는 발음만, 두 번째 청취는 멈춤·강세·억양만** 본다.
한 번에 전부 고치려 하면 아무것도 안 고쳐진다.

### 모의고사 출제

별도 전용 문제 없이 파트별 연습과 같은 풀에서 뽑되, 무작위가 아니라 **가중 추출**이다.

| 신호 | 가중치 |
|---|---|
| 아직 안 푼 문항 | 400 (최우선) |
| 자가채점이 낮음 | +0~120 |
| 오래 안 봄 | +0~90 |
| 여러 번 품 | −0~25 |

상위 N개를 그냥 자르면 다 푼 뒤 매번 같은 문항만 나와 굳는다. 그래서 이 값을 **확률 가중치**로 쓴다.
못한 문항이 자주 돌아오되 잘한 문항도 가끔 나온다. 기록이 없으면 순수 무작위로 되돌아간다.

## 시험 구성 (2026년 현행)

11문항 · 약 20분 · 5개 과제 유형. 구 Part 5 *Propose a Solution* 은 2021-08-07 삭제되어 다루지 않는다.

| 파트 | 문항 | 과제 | 준비 | 답변 | 배점 |
|---|---|---|---|---|---|
| 1 | Q1–2 | Read a text aloud | 45초 | 45초 | 0–3 |
| 2 | Q3–4 | Describe a picture | 45초 | 30초 | 0–3 |
| 3 | Q5–7 | Respond to questions | 3초 | 15·15·30초 | 0–3 |
| 4 | Q8–10 | Respond using information | 자료 45초 + 각 3초 | 15·15·30초 | 0–3 |
| 5 | Q11 | Express an opinion | 45초 | 60초 | 0–5 |

재현한 실전 디테일:

- 준비 시간이 끝나면 클릭 없이 자동으로 녹음이 시작된다. 일시정지·되감기 없음.
- **Q10은 질문 음성이 2회 재생된다.**
- Part 4는 문항 전에 자료 읽기 45초가 따로 붙는다.
- 답변 중 중단하면 그 문항은 저장되지 않는다.
- 모의고사 모드에서는 지시문을 건너뛸 수 없다.

## 파일 구조

```
app/
├─ index.html
├─ css/style.css
└─ js/
   ├─ questions.js   문항 뱅크 · 모범답안 · 팁 · 출처 메타 · 공식 링크
   ├─ patterns.js    v2 유형 · 만능 문장 · 드릴 상황 · TYPE_OF 매핑
   ├─ drill.js       v2 드릴 엔진 + 형식 검사기
   ├─ store.js       IndexedDB(녹음) + localStorage(설정)
   ├─ recorder.js    MediaRecorder · 입력 레벨 · 비프음 · TTS
   ├─ engine.js      시험 상태기계 + 실행 목록 생성
   └─ app.js         라우팅 · 화면 렌더 · 시험 오버레이
```

## 문항 추가

`js/questions.js` 의 `PART1`~`PART5` 배열에 객체를 하나 넣으면 끝이다. 빌드 불필요.

```js
{
  id: 'p1-09', tone: '안내 방송',
  text: '읽을 지문 원문',
  model: '의미 단위 / 표시와 STRESS 대문자, 억양 ↘ 를 넣은 모범 낭독',
  focus: ['어려운', '단어들'],
  tips: ['이 문항에서 잡아야 할 것', '...'],
  note: '지문 성격과 톤'
}
```

Part 3·4는 `items` 배열에 `{ q, sec, model, tips }` 를 넣는다. Part 4는 `material` 표와
Q10에 해당하는 항목에 `repeat: true` 를 붙인다.

**세트당 3문항을 유지해라.** 더 넣어도 파트별 연습에서는 전부 나오지만, 풀 모의고사는
앞의 3문항만 사용해 총 11문항을 지킨다.

Part 2 사진을 추가하려면 `SCENE` 객체에 SVG를 하나 넣고 `scene: SCENE.<이름>` 으로 참조한다.
`person(x, y, scale, color, pose)` 헬퍼가 있다. pose는 `'arm-up'`, `'arms-fwd'`, `null`.

## 저작권

`js/questions.js` 상단의 `SOURCE_META` 가 이 앱 콘텐츠의 출처를 명시한다.

```js
{ sourceType: 'original', sourceName: '자체 제작', license: 'owned',
  audioType: 'tts-browser', examFormatVerifiedAt: '2026-08-25' }
```

공식 자료는 `OFFICIAL` 의 링크 목록으로만 관리한다. 공식 MP3 주소를 `<audio src>` 로 삽입하거나
공식 사진·정보표를 복사해 문항으로 쓰지 마라. 링크 이동만 허용된다.

**권장 사용 순서** — ① 이 앱에서 녹음 → ② 모범답안·팁 대조 → ③ 공식 수준별 샘플에서 고급 답변 청취
→ ④ 같은 문항 재녹음. 공식 기출 Test는 2주에 한 번 실전 점검용으로만 써라. 매일 풀면 금방 소진된다.

## 데이터

IndexedDB `toeic-speaking` v2 — `attempts`(녹음) / `drills`(드릴 결과) / `coverage`(Part 2 블록).
v1에서 올라와도 기존 녹음은 보존된다.

녹음은 이 브라우저의 IndexedDB에만 저장된다. 서버로 전송되지 않고, 저장소에도 올라가지 않는다.
물리적으로는 브라우저 프로필 폴더 안에 있어서 이 프로젝트 폴더 밖이다 — git 이 볼 수 없는 위치다.
브라우저 데이터를 지우면 함께 사라진다. `기록` 화면에서 개별·전체 삭제할 수 있다.

## 브라우저

Chrome · Edge · Safari에서 동작한다. 영어 TTS 품질은 macOS Safari가 가장 낫다
(`설정 → 영어 음성`에서 Samantha 권장).

소스를 고친 뒤 화면이 그대로면 하드 리로드(Mac ⌘⇧R / Windows Ctrl+F5)해라. 정적 파일이 캐시된 것이다.

## 알려진 제약

- 시험 중 다른 탭으로 전환하면 브라우저가 타이머를 1초 단위로 스로틀링한다.
  구간이 최대 1초까지 길어질 수 있다. 저장되는 답변 길이는 제한 시간으로 잘라내지만,
  **연습 중에는 탭을 떠나지 마라.** 실전에서도 못 떠난다.
- Part 2 사진은 간이 SVG 장면이다. 묘사 연습에는 충분하지만 실제 시험 사진의
  디테일 밀도에는 못 미친다.
